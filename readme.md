## 🌟 Overview

D2R-AI-Item-Tracker uses advanced AI to help you gather item tooltips from screenshots of Diablo II: Resurrected. This tool makes item tracking simpler by utilizing Vision LLMs from OpenAI, Groq, OpenRouter, and LM Studio/Ollama. It does not require Tesseract or EasyOCR, so you can start extracting information right away without complex setups.
